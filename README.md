# BK Law Skills for Claude

Bankruptcy practice skills for Claude: 341 meeting emails, client document requests, and more.

## Install

1. In Claude, open **Settings > Plugins > Add** and add this marketplace: `bklawskills/plugins`
2. Install the **bk** plugin.
3. When Claude asks, sign in with your BK Law Skills account.
4. Type `/bk:hello` to confirm everything is connected.

A BK Law Skills account is required. Learn more at https://bklawskills.com.
